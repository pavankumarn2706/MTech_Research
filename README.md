# MTech Research - Project Documentation

This folder contains all presentation and documentation materials for the MTech Research program. The files are organized chronologically according to the research submission process.

## File Structure

### 📋 Phase-wise Documentation

#### 1. **RPAC.zip** - Research Proposal and Approval
- **Stage**: First submission - Research Proposal
- **Contents**: RPAC (Research Proposal Approval Committee) presentation and documentation
- **Purpose**: Initial research proposal submission for approval by the committee
- **Status**: Baseline proposal document

#### 2. **Progress.zip** - Progress Presentation
- **Stage**: Mid-stage submission - Research Progress Review
- **Contents**: Progress presentation materials and updates
- **Purpose**: Demonstrate research progress made since the initial proposal
- **Status**: Intermediate milestone

#### 3. **synopsis_report(1).zip** - Synopsis Report
- **Stage**: Pre-Thesis submission - Synopsis/Pre-Synopsis
- **Contents**: Synopsis documentation and pre-thesis materials
- **Purpose**: Final synopsis before thesis preparation; serves as a bridge between progress and final thesis
- **Status**: Pre-final submission

#### 4. **My_Thesis_original.zip** - Final Thesis Report
- **Stage**: Final submission - Complete Thesis
- **Contents**: Complete thesis report and final research documentation
- **Purpose**: Final thesis submission with complete research work
- **Status**: Final milestone
